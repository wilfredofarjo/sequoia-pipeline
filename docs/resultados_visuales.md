# Resultados visuales

## Sesión 2026-08-21

La siguiente figura muestra una visualización del **NDVI** calculado sobre el ortomosaico multiespectral generado en Agisoft Metashape Professional para la sesión del **21 de agosto de 2026**.

![Visualización del NDVI de la sesión 2026-08-21](img/ndvi_sesion_2026-08-21.png)

**Figura 1.** Visualización del NDVI sobre el ortomosaico multiespectral de la sesión 2026-08-21. La escala de color representa valores del índice entre 0 y 1. Esta imagen se incluye como evidencia visual del flujo de reconstrucción SfM, escalado métrico, calibración radiométrica y cálculo de índices.

La figura tiene una función **documental y de control visual**. El análisis cuantitativo posterior debe realizarse sobre los rásteres exportados y las estadísticas derivadas del dosel, no sobre la imagen renderizada.

## Interpretación metodológica

La visualización permite comprobar de forma cualitativa que el dosel presenta una señal NDVI espacialmente diferenciada respecto a la estructura del contenedor y otras superficies no vegetales. No se utiliza esta vista para inferir por sí sola diferencias fisiológicas entre plantas o zonas del dosel.

El flujo completo asociado a esta figura se considera validado únicamente para la sesión **2026-08-21**. Las sesiones **2026-05-28** y **2026-07-10** deben reproducir el mismo procedimiento antes de realizar comparaciones temporales.

## Productos recomendados por sesión

Para cada fecha se recomienda conservar:

- ortomosaico multibanda calibrado;
- ráster NIR;
- NDVI;
- GNDVI;
- EVI2, una vez estandarizado;
- figuras de control visual;
- tabla de estadísticas del dosel;
- reporte de parámetros y control de calidad.

NDRE permanece fuera del análisis principal hasta completar la validación radiométrica del canal Red Edge.
